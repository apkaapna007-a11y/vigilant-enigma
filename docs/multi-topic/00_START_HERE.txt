❓ FAQ

Q: Will this break my existing code?
A: No! Single mode is 100% preserved. Batch mode is entirely new.

Q: How long does setup take?
A: ~10 minutes from download to deployment.

Q: Do I need to install new packages?
A: No! Uses your existing Next.js, React, TypeScript stack.

Q: How many topics can I process?
A: No hard limit. Tested smooth up to 50+ topics.

Q: How long does processing take?
A: ~1-2 minutes per article (sequential). Pause/resume anytime.

Q: Do results auto-save?
A: Yes! Each topic saves to history immediately upon completion.

Q: Can I retry failed topics?
A: Yes! Each failed topic has a retry button.
