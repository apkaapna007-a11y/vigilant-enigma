COMMON SETUP MISTAKES & SOLUTIONS
================================================================================

❌ "Components not found" error
✅ Make sure multi-topic-*.tsx are in components/ folder
✅ Check import paths match your project structure

❌ "Type 'Topic' not found"
✅ Verify lib/types.ts was updated with new interfaces
✅ Check TypeScript intellisense is showing new types

❌ "Batch mode button doesn't appear"
✅ Verify upload-tab.tsx was replaced (old version still active)
✅ Clear .next folder: rm -rf .next
✅ Restart dev server

❌ "Processing doesn't start"
✅ Check API key in Settings tab
✅ Verify each topic has title + keyword
✅ Check browser console for errors

❌ "Results not saving to history"
✅ Check browser storage quota
✅ Try with smaller batch (5 topics instead of 50)
✅ Look at browser localStorage size

❌ "Styles look broken"
✅ Verify Tailwind CSS is loaded
✅ Check tailwind.config.ts content paths
✅ Clear browser cache
